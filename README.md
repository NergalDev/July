# 🧸 ЛогоДруг (LogoDrug)

Интерактивное кроссплатформенное веб-приложение (PWA) для автоматизации звуков, контроля речевого развития детей и взаимодействия родителей со специалистами-логопедами.

Проект разработан на базе фреймворка Flask и представляет собой полноценное production-ready решение с интеграцией современных браузерных и серверных технологий.

---

## ✨ Ключевой функционал

### 🔹 Для родителей и детей:
* **Интерактивный блок обучения:** Упражнения по постановке и автоматизации звуков с поддержкой адаптивного медиа-контента.
* **Встроенный диктофон:** Использование **Web Audio API** для записи произношения ребенка в реальном времени с возможностью мгновенного прослушивания для оценки дикции.
* **Геймификация процесса:** Внедрение интерактивных эффектов (визуальные салюты/конфетти через JS) для повышения мотивации ребенка при завершении заданий.
* **Трекинг прогресса (Бэкенд-аналитика):** Автоматический подсчет и сохранение количества пройденных карточек по каждому звуку в базу данных с выводом красивой инфографики в личном кабинете.
* **Онлайн-диагностика с экспортом в PDF:** Интеллектуальный тест-опросник речевых нарушений. Результат генерируется динамически в виде официального экспертного заключения, которое можно скачать в формате PDF с помощью библиотеки `html2pdf.js`.
* **Запись на прием:** Удобный интерфейс выбора даты/времени консультации с системой отслеживания статуса оплаты занятий.

### 🔹 Для администратора (Кабинет логопеда):
* **Панель управления контентом:** Защищенный административный интерфейс для динамической загрузки новых дидактических материалов и карточек в базу данных через веб-форму.
* **Безопасная обработка файлов:** Интеграция с компонентами `werkzeug.utils.secure_filename` для предотвращения уязвимостей при загрузке изображений на сервер.
* **Менеджмент записей:** Просмотр графика приемов и финансовой аналитики (общий доход клиники).

## 🛠 Технологический стек

* **Backend:** Python 3.10+, Flask, Flask-SQLAlchemy (ORM), Flask-Login (сессии и авторизация), Werkzeug (безопасность).
* **Database:** SQLite (развертывание и миграции таблиц «на лету»).
* **Frontend:** HTML5, CSS3, Bootstrap 5 (адаптивная верстка под мобильные устройства).
* **JavaScript & Web APIs:**
  * **Web Audio API** (работа с медиа-потоками микрофона).
  * **Service Workers & Web App Manifest** (концепция PWA для установки сайта на смартфон как нативного приложения).
  * `canvas-confetti` (анимационный движок геймификации).
  * `html2pdf.js` / `html2canvas` / `jsPDF` (клиентская генерация документов).

## 🚀 Архитектура базы данных

Реляционная модель данных включает в себя следующие связанные сущности:
1. `User` — учетные записи (роли: `parent`, `logoped`) с хешированием паролей.
2. `Exercise` — база логопедических карточек и видеоуроков по категориям и звукам.
3. `Progress` — транзакционная таблица успеваемости (связь Many-to-One к пользователю).
4. `Appointment` — расписание сессий и статусы биллинга.
5. `Payment` — история финансовых транзакций.

## 💻 Локальное развертывание

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/ВАШ_ЛОГИН/logodrug.git](https://github.com/ВАШ_ЛОГИН/logodrug.git)
   cd logodrug
Создайте и активируйте виртуальное окружение:

Bash
python -m venv .venv
# Для Windows:
.venv\Scripts\activate
# Для macOS/Linux:
source .venv/bin/activate
Установите зависимости:

Bash
pip install flask flask-login flask-sqlalchemy werkzeug
Запустите сервер разработки:

Bash
python app.py
Приложение будет доступно по адресу http://127.0.0.1:5000. При первом запуске база данных со всей структурой таблиц сгенерируется автоматически.

### 2. Как отправить новую версию на GitHub

Выполнять команды можно прямо в Терминале твоей среды разработки (PyCharm / VS Code) на компьютере.

#### Если проект уже привязан к GitHub ранее:
Открой терминал в корне проекта и введи три команды по очереди:

1. **Добавляем все новые файлы, включая README, манифесты и шаблоны в индекс Git:**
   ```bash
   git add .
Создаем коммит с фиксацией масштабного обновления:

Bash
git commit -m "feat: add progress tracking, gamification, dictaphone, PDF export and PWA features"
Отправляем изменения на GitHub:

Bash
git push origin main
(Если ветка называется мастер, то git push origin master).

Если репозиторий создается впервые (чистый гит):
Если ты создавал новый аккаунт или до этого гит не настраивал, зайди на свой GitHub, нажми New Repository, назови его logodrug (сделай его Public) и нажми Create. GitHub покажет тебе список команд. Скопируй их и выполни в терминале своего компьютера:

Bash
git init
git add .
git commit -m "initial full expert version"
git branch -M main
git remote add origin https://github.com/твой_логин_гитхаба/logodrug.git
git push -u origin main
